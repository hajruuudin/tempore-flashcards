# TemporeFlashcards

**A Free, Open-Source Flashcards Application for Mac and iPhone**

## Overview

TemporeFlashcards is a local, self-hosted flashcards application designed to break free from the paywall restrictions imposed by commercial flashcard apps. Built with a focus on user freedom and data ownership, this application allows you to create, study, and sync your flashcards across your Mac and iPhone devices seamlessly.

## Why TemporeFlashcards?

Modern flashcard applications often lock essential features behind expensive subscriptions and paywalls. TemporeFlashcards is our answer to this problem:

- ✅ **Completely Free** - No subscriptions, no hidden fees
- ✅ **Open Source** - Transparent, community-driven development
- ✅ **Self-Hosted** - You own your data
- ✅ **Cross-Platform** - Works on Mac and iPhone with seamless sync
- ✅ **Privacy-Focused** - Your study data stays under your control

## Architecture

TemporeFlashcards uses a modern, distributed architecture:

- **Frontend**: Native applications for Mac (macOS) and iPhone (iOS)
- **Backend**: Supabase - providing real-time database sync, authentication, and storage
- **Data Sync**: Automatic synchronization across all your devices through Supabase

## Features

- Create and organize flashcards and decks
- Study with spaced repetition algorithms
- Sync seamlessly across Mac and iPhone
- Self-hosted backend using Supabase
- No data mining, no ads, no paywalls
